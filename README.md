# Atlas — Plateforme de voyage *(nom de code)*

Plateforme éditoriale de découverte de voyage, conçue pour devenir une référence mondiale via le **SEO** et monétisée par **Google AdSense** (puis affiliation & premium).

> ⚠️ **Projet en phase d'architecture.** Aucun code applicatif n'est encore développé. Le développement démarrera après validation de l'analyse.

## Avancement par phases

| Phase | Objet | Statut |
|---|---|---|
| **Phase 1** | Analyse & architecture complète | ✅ Livrée — **en attente de validation** |
| Phase 2 | Design premium + stratégie SEO détaillée | ⏳ En attente Phase 1 |
| Phase 3 | Développement (Next.js, TS, Prisma, PostgreSQL…) | ⏳ |
| Phase 4 | Mise en production, optimisation, sécurité, audit | ⏳ |

## Stack cible (Phase 3)

Next.js (App Router) · React · TypeScript · Tailwind CSS · Prisma · PostgreSQL · NextAuth · Server Components

## Principes directeurs

- **SEO-first** : rendu serveur, données structurées, programmatic SEO encadré.
- **Performance** : Core Web Vitals « Good », Lighthouse > 95.
- **Sécurité & RGPD** dès la conception.
- **Accessibilité** WCAG 2.2 AA.
- **Monétisation maîtrisée** (AdSense sans dégrader l'UX/CWV) + diversification.
